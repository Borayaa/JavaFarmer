# Hats

You have unlocked a few new hat colors for your drone.

Equip them like this:
`farm.changeHat(.Gray_Hat);
farm.doAFlip();
farm.changeHat(.Purple_Hat);
farm.doAFlip();
farm.changeHat(.Green_Hat);
farm.doAFlip();
farm.changeHat(.Brown_Hat);
farm.doAFlip();`

`.Gray_Hat` is short for `farm.Hat.Gray_Hat`: the function already knows that it wants a hat.
