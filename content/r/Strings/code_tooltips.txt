@code_tooltip_range = R has no `range()`. Count with a sequence in a `for` loop instead:
`seq_len(n)` counts from `1` to `n`.
`seq_len(n) - 1` counts from `0` to `n - 1` (like Python's `range(n)`).
`a:b` counts from `a` to `b`, both included.
`seq(a, b, by = step)` counts from `a` to `b` in steps of size `step`.

takes `1` tick to start the loop.

example:
`for (i in seq_len(10) - 1) {
    print(i)
}

for (i in 2:5) {
    print(i)
}

for (i in 10:1) {
    print(i)
}`

@code_tooltip_set_execution_speed = `set_execution_speed(speed)`
Limits the speed at which the program is executed to better see what's happening.

A `speed` of `1` is the speed the drone has without any speed upgrades.
A `speed` of `10` makes the code execute `10` times faster and corresponds to the speed of the drone after `9` speed upgrades.
A `speed` of `0.5` makes the code execute at half of the speed without speed upgrades. This can be useful to see what the code is doing.

If `speed` is faster than the execution can currently go it will just go at max speed.

If `speed` is `0` or negative, the speed is changed back to max speed.
The effect will also stop when the execution stops.

returns `NULL`

takes `200` ticks to execute.

example:
`set_execution_speed(1)`

@code_tooltip_is.null = `is.null(x)` is `TRUE` if `x` is `NULL`, `FALSE` otherwise.
@code_tooltip_as.character = `as.character(x)` turns a value into text: `as.character(5)` is `"5"`.
@code_tooltip_switch = Chooses code depending on a text: `switch(name, a = { ... }, b = { ... }, { ... })`. The last arm without a name runs when no name matches.
@code_tooltip_floor = `floor(x)` rounds `x` down to a whole number. Use `floor(x + 0.5)` to round to the nearest whole number.
@code_tooltip_nchar = `nchar(text)` returns the number of characters in a text.
